用法

网页脚本：编辑器里是一个 async 函数体，dev 的方法与 Python wwb.Device 同名同参（关键字参数写成最后的 {flush: true}）。 另有 sleep(ms)、frame()、pacer(hz)、now()、canvas()、mx(...)、segText(s)、log(...)。

Python 程序：运行 python -m wwb.sim，用它打开的网址访问本页，然后程序里用 Device("sim")， 或命令行加 --port sim，例如 python -m wwb.showcase --port sim。

两种方式发出的都是协议帧，模拟器按固件的命令处理逐条执行，并模拟真机的刷新时序（OLED 约 95fps、数码管只写变化的位、输入 20ms 消抖）。
