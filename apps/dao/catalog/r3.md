# r3 法事：手诀·法器·步罡

道士行法讲究“手掐诀、脚踏罡、口念咒、手执法器”。本批 9 个场景：一个结手诀，一个踏罡步，七个各用一件法器
（帝钟、拂尘、七星剑、令牌、龙角、葫芦、照妖镜）。每个场景的主体画面都不一样。
公用小工具（描边粗线、旋转、道袍袖、轮次）放在 `rituals/r3_kit.py`。

## r3.shoujue 掐诀
- 依据：掐诀多用左手（右手执剑、执铃）。手型据民间道坛流传的诀谱：剑诀（食、中二指并伸，拇指压无名指和小指）、
  灵官诀（中指直竖，食指屈来掐中指第一节，拇指相抵）、五雷诀（四指屈入掌心，拇指压在指背上如握拳）、
  三山诀（握拳后依次弹出食指、小指、拇指）。参考 https://www.sohu.com/a/452977275_488666
- 入场：道袍袖托着一只张开的左手从下方弹上来，四指依次屈下，结成剑诀，指尖冒出剑气。
- 持续：一轮 600 秒，依次结四诀，每诀 150 秒，换诀时手指平滑过渡。每诀各有气象：剑诀指尖一道光剑并有流光上冲，
  灵官诀中指尖一团灵官火，五雷诀拳边雷光乱闪，三山诀身后升起三座山。手外一圈点状“气圈”随本诀时间合拢。
  左侧竖写诀名，右侧写“第几遍”。四诀走完后甩手散诀（张开一抖，余气散出），再结剑诀开始下一遍。
- 中断 / 恢复 / 圆满：中断时手松开、垂下，文字变成“松诀 / 暂歇”。恢复时手抬起重新结诀。
  圆满时四诀快速连掐一遍，每结成一诀闪一圈光，然后握拳收诀，四周光芒放射，题“道法自然”（《道德经》）。
- 点阵：一只迷你手，四列的高度表示四指的伸屈，拇指伸出时左上多两点。五雷诀时角上闪雷点；圆满时光圈扩散。

## r3.dizhong 摇帝钟
- 依据：帝钟又名三清铃、法铃，铜制，柄端作三叉（“山”字形，象征三清），摇铃召神驱邪。
  九重天见《楚辞·天问》“圜则九重”。圆满句“声闻于天”出自《诗经·小雅·鹤鸣》。
- 入场：右手执帝钟从上方落下（弹性停住），开始摇摆，第一声响起，声波荡开，右侧九重天的梯级逐层显现。
- 持续：钟身按单摆摇动，钟舌滞后，摆到两端时敲响，每响一声荡出一圈声波。一轮 540 秒，一团声光沿九重天每 60 秒
  上升一层，层名（一重天……九重天）跟着亮光移动；已到达的层画成实线，顶上是天门。
  续：天门打开，一道光落回钟上，九层依次暗下，天门再关上。
- 中断 / 恢复 / 圆满：中断时摆动阻尼停下，左手掌托住钟口。恢复时手撤开，摆幅渐大。
  圆满时急摇，声光一口气升满九层，天门大开、光芒放射，题“声闻于天”。
- 点阵：小钟左右摆，敲响时一侧冒出声点；圆满时天门加光圈。

## r3.fuchen 挥拂尘
- 依据：拂尘（麈尾、云帚）是道士随身法器，取“拂去尘埃、清净自守”之意。文字取《太上老君说常清静经》
  “人能常清静，天地悉皆归”。
- 入场：尘埃从左边飘来蒙住太极，太极变暗；右手执拂尘从右下伸入，拂尘毛垂着轻轻晃动。
- 持续：每 6 秒拂一次，动作分抬起、横扫、回落三段。拂尘毛有滞后，静止时下垂，扫动时顺势甩开。
  被这一扫轮到的尘埃会飞出画外。一轮 600 秒，46 粒尘埃被逐渐拂净，太极由暗（抖动淡出）转明，并缓缓转动。
  左侧竖写“常清静”，左下写“几拂”。续：一阵风吹过，尘埃重新飞来，太极复暗。
- 中断 / 恢复 / 圆满：中断时拂尘放低，写“暂歇”；恢复时拂尘抬回。圆满时连扫两下，余尘一扫而光，
  太极全亮、快转、放光，题“天地悉皆归”。
- 点阵：剩下的尘埃（随机点，越来越少）加一个拂尘小图标，扫动时有一道竖线扫过；圆满时光圈扩散，最后变成太极。

## r3.qixing 七星剑
- 依据：七星剑是道教法剑，剑身嵌北斗七星，用来召将斩邪。北斗七星为天枢、天璇、天玑、天权、玉衡、开阳、摇光，
  星君名为贪狼、巨门、禄存、文曲、廉贞、武曲、破军（《北斗七星延命经》）。“气冲斗牛”化用《晋书·张华传》
  中宝剑之精上彻斗牛的典故。
- 入场：右手持剑从左下挥入，剑身一道流光划过，天上北斗的七个星位淡淡显现。
- 持续：一轮 630 秒，剑身七星每隔约 85 秒点亮一颗（菱形星，偶有闪光）。每亮一颗，天上对应的星先降下一道光到剑上，
  天上北斗随之连线成形。右侧竖写当前星君名。每 24 秒挽一个剑花（剑绕手转一圈，带剑尖残影）；
  每 7 秒有一道流光走过剑身。续：七星齐明后剑指北斗，七颗星飞上天融入北斗、一齐闪光，剑身复暗，从头再来。
- 中断 / 恢复 / 圆满：中断时剑放平，天上北斗变暗，写“按剑”；恢复时剑扬起，流光走过。
  圆满时余下的星依次补亮，剑一扬，七道星光从剑上直射北斗七星，北斗大放光明，题“气冲斗牛”。
- 点阵：北斗七星（亮了的常亮，下一颗闪烁）加右下一柄斜剑。

## r3.lingpai 令牌拍案
- 依据：五雷令牌为长方木牌，正面刻“令”或“五雷号令”，明《上清灵宝济度大成金书》载其以雷击枣木制成。
  行法时以令牌击案、调遣兵将。民间道坛与闾山法有东、南、西、北、中“五营兵马”的说法。
  参考 https://en.daoinfo.org/wiki/Commandment_Plaques
- 入场：法案从下方升起，手持令牌从上方落下，“啪”地立在案上，冲击线和扬尘向两边散开。桌帷上写“五营兵马”。
- 持续：每 20 秒拍一次案：手从右上伸来捏住令牌，提起后猛拍下去，案面一震、尘起，点阵全亮一闪。
  拍案之间令牌边框上有一点灵光走过，牌顶袅袅冒灵气。一轮 600 秒，东、南、西、北、中五营令旗各在一次拍案后
  弹出立定（燕尾旗面迎风飘），桌帷上随之写“某营兵马到”。续：五营令旗齐飞出画（“五营齐发”），再从头点兵。
- 中断 / 恢复 / 圆满：中断时令牌向后倒下卧在案上，旗面停止飘动、下垂，写“收令暂歇”。恢复时手扶令牌重新立起。
  圆满时连拍三下，一下比一下重（一拍、二拍、三拍），五营令旗齐到，令牌放光，令旗升天，桌帷上写“五雷号令”。
- 点阵：令牌图标；令牌提起时图标上移，拍下时底行闪烁；已到的营在四周各亮一点；圆满时光圈扩散。

## r3.bugang 步罡踏斗
- 依据：步罡踏斗源于禹步，道士在铺开的罡单（星图）上按星位行步，配合掐诀念咒以“步天”。
  禹步“步不相过”：前脚迈出，后脚跟上并拢。北斗七星加左辅、右弼两颗隐星为九星，对应“三步九迹”。
  参考 https://en.daoinfo.org/wiki/Pacing_the_Big_Dipper 、https://en.wikipedia.org/wiki/Bugang
- 入场：俯视罡单，九个星位与北斗虚线逐个显现，一双云履从下方走来，踏上天枢。
- 持续：一轮 630 秒、九步，每 70 秒迈一步：前脚抬起（放大并在地上投影）落到下一颗星，落地时激起一圈涟漪、
  星被踏亮，后脚跟上并拢。走过的罡步连成实线。右侧上下竖写星名和星君名（如“天枢 / 贪狼”“辅星 / 左辅”）。
  续：“回罡 / 复始”，双脚一跳一星倒退回天枢，星一颗颗熄灭。
- 中断 / 恢复 / 圆满：中断时罡单变暗，写“住罡 / 暂歇”；恢复时变亮，脚下涟漪一圈。
  圆满时余下的星位快步踏完，九星齐亮连成北斗，绕斗心转动，题“斗转星移”，侧写“九迹 / 圆满”。
- 点阵：九个星位，已踏的常亮，当前的闪烁，未踏的偶尔一闪。

## r3.longjiao 吹龙角
- 依据：龙角（牛角号）是闾山、正一等派常用的法器，开坛召营时吹角，以号令兵马、通达三界。
- 入场：弯弯的牛角号由手握着从下方举起，吹响第一声，角声的弧线从喇叭口荡出。
- 持续：每 10 秒吹一声，持续约 3 秒，吹时角身微颤、声弧一道道荡出。一轮 540 秒，每 30 秒有一名天兵驾小云从天而降
  （弹跳落定、闪光），在右侧三排云头上列阵，先站满前排再站后排，共 18 名。续：满阵天兵连云带人往上开拔出画
  （写“开拔”），再一名一名重新降下。
- 中断 / 恢复 / 圆满：中断时号角放低，写“歇角”；恢复时号角举回，再吹一声。
  圆满时吹一声长角，余下的天兵一齐降下，举枪，全阵开拔升天，题“兵马齐至”。
- 点阵：已到的天兵按三排六列点亮；吹角时顶行流动的声波点。

## r3.hulu 葫芦收妖
- 依据：葫芦是道家常见法器，也是“壶天”意象的来源（《后汉书·方术传》中壶公悬壶，壶中别有天地）。
  民间道法与小说中常以葫芦收妖、贮丹。
- 入场：葫芦从上方落下、弹跳停稳，塞子“啵”地弹开飞走，左边地上冒起一团瞪着眼的妖气（抖动灰度的雾团，
  有横眉、眼珠斜瞟葫芦、锯齿嘴）。
- 持续：妖气朝葫芦口被拉长，一粒粒螺旋着吸进去。每 15 秒有一只小鬼被整只扯出来、拉长、吞进口，
  葫芦随之一抖、口上一闪。一轮 600 秒，妖气从大团缩到只剩一双眼。右侧竖写“第几妖”。
  续：塞子落回塞口，葫芦猛抖、放光，左边又冒出一团新妖气，塞子再弹开。
- 中断 / 恢复 / 圆满：中断时塞子落回塞口、吸力停止，写“塞口”；恢复时塞子弹开，再吸。
  圆满时猛吸一口，整团妖气被拉成一条吞进去，塞口，葫芦剧烈抖动后放光，题“邪祟尽收”。
- 点阵：葫芦图标，肚里随收妖进度“装满”；开口时口上闪，塞口时口上点亮。

## r3.zhaoyao 照妖镜
- 依据：葛洪《抱朴子·登涉》：“万物之老者，其精悉能假托人形……唯不能于镜中易其真形耳。
  是以古之入山道士，皆以明镜径九寸已上，悬于背后，则老魅不敢近人。”
- 入场：一位“客人”走进画面（书生、女子或老翁，按种子轮换），右上写“书生？”；手举宝镜从下方升起，一闪，
  射出镜光。
- 持续：镜光是一束点状光锥，缓缓上下扫。光照到的部分显出原形，其余仍是伪装：书生是狐（尖耳、吊梢眼、大尾巴），
  女子是白骨，老翁是蛇。一轮 600 秒，镜光从一线逐渐张到很宽，越到后面原形露得越多，来客也会不时发抖。
  镜面有斜光扫过。续：镜光大张、原形毕露（“狐妖！”），妖物尖叫着逃出画外，下一位客人走进来。
- 中断 / 恢复 / 圆满：中断时镜子侧过去（变成窄椭圆），镜光熄灭，写“收镜”；恢复时镜面转回，一闪，镜光重开。
  圆满时镜光转正、张满，原形自下而上显出，镜子放光，题“现出原形”，然后妖物发抖、淡去，化一缕烟散尽。
- 点阵：小镜（圆圈加柄），右边三条光线随镜光的角度和宽度摆动。
