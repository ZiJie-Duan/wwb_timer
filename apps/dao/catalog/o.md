# 起卦（o）与特殊场景（s.boot / s.reset）

共用：`omens/o_common.py`（爻从中间长出、揭晓版式、弹出标签）、`omens/o_data.py`（六十四卦卦辞摘句、先天八卦数）。
揭晓（最后 1.7 秒）统一版式：左边卦象（变爻右侧一个小方点），右上 `full_name`（如“水雷屯”）与“第几卦”，
一道虚线，底行打字机写出卦辞摘句；点阵 `mx_hexagram`，揭晓瞬间亮度 5。

卦辞：依《周易》通行本（王弼本）经文，每卦取首句或最有名的一句，连续原文、不增字，按 12px 一行 ≤ 10 字截取。
震卦首句“震来虩虩”的“虩”字库缺字，改取同卦辞“震惊百里，不丧匕鬯”。

## o.coins 金钱课
- 依据：火珠林法（三钱法）。三枚方孔钱，一背为单（少阳 7）、两背为拆（少阴 8）、三背为重（老阳 9）、三字为交（老阴 6）。
- 画面：右侧三枚方孔钱（字面空心带四点“字”，背面实心）一齐抛起、翻转、落地弹跳扬尘；落定后弹出“单·少阳”等标签，
  左边卦象自下而上长出一爻。六掷约 5 秒，揭晓时三钱沉下去。
- 点阵：已成之爻；钱在空中时顶行跑点，落地后底行显示三钱（背亮）。

## o.jiaobei 掷筊
- 依据：台闽庙宇的掷筊（博杯）。筊杯新月形，一面平一面凸：一平一凸为圣筊，两平为笑筊，两凸为阴筊（怒杯）。
  资料：[cmoney 筊象说明](https://www.cmoney.tw/notes/note-detail.aspx?nid=106819)、[uptogo](https://uptogo.com.tw/命理/怎麼問神？/)。
- 映射（本作的游戏化约定，非传统）：笑筊 = 老阳 9，阴筊 = 老阴 6，圣筊：左杯平面朝上 = 少阳 7，右杯平面朝上 = 少阴 8。
- 画面：两只筊杯从地上拾起、合成一轮满月（合掌一拜），抛出翻转，落地摇晃（平面朝上空心带木纹，凸面朝上实心带高光），
  弹出“圣筊·少阳”等；左边卦象长出。
- 点阵：底行两块（平面朝上为一横、凸面为一点）。

## o.qian 求签
- 依据：庙宇求签。用“六十四卦签”的做法：签号 1–64 即文王卦序，只出本卦，无变爻。
- 画面：签筒从下弹入，前倾摇动（筒身竹节、签牌，九支签抖动，“哗哗”声线），其中一支越探越高、跳出翻落；
  签筒退场，那支签立起放大到整屏高，竖写“第十八签”，一圈闪光；揭晓时签滑出画外。左侧竖排“诚心求签”。
- 点阵：摇动的签筒 → 落地的签 → 一支竖签。

## o.meihua 观梅占
- 依据：《梅花易数·卷一》“观梅占”（邵雍见二雀争枝坠地而起卦）与“年月日时起例”：年月日为上卦，年月日加时总数为下卦，
  总数除六取动爻；子年一数……亥年十二数，时同；先天数乾一兑二离三震四巽五坎六艮七坤八。
  原文：[维基文库 梅花易数/卷一](https://zh.wikisource.org/wiki/梅花易數/卷一)。
- 取上位机本地时间；**月、日用公历数代替农历**（没有农历表），年按公历年份取干支（立春/春节前后会差一年）。
  同一时辰内起出的卦相同（这是梅花易数的本义）。
- 画面：梅枝横贯全屏生长、梅花次第绽开；两只麻雀立枝上相向跳斗扑翅，扭打坠地，花瓣震落，又惊飞；画面抖动淡出。
  转入算式：“丙午年 子时 / 10月24日”，`7+10+24=41 ÷8余1` → 乾（上），`+1=42 ÷8余2` → 兑（下），`42÷6余0` → 六爻动。
- 点阵：一朵梅花（坠地时花心亮）→ 上卦 → 下卦（动爻时顶行闪）。

## o.dayan 大衍筮
- 依据：《周易·系辞上》“大衍之数五十，其用四十有九。分而为二以象两，挂一以象三，揲之以四以象四时，归奇于扐以象闰。”
  三变成一爻：每变去 挂一 + 两把余数，三变后剩 36/32/28/24，除四得 9/8/7/6。十八变成卦（按真实算法用 rng 分二，
  分把用正态分布模拟手分）。
- 画面：第一变逐步演示（约 3.9 秒），每一步上方打出对应的系辞原句：五十根蓍草排开；取一根横置不用；分成两把；
  右把取一根挂到左下；两把四根一组依次落下消失，余数抬起；余数归到左下。底部显示 `49-5=44`。
  其余十七变快进：右侧一捆蓍草分把、减少（下方数字），标题“第几爻”，左边逐爻长出，弹出“九·老阳”等。
- 点阵：一捆蓍草（分把时中间空一列）→ 已成之爻 + 底行余数长度条。

## o.fuji 扶乩
- 依据：扶乩（扶鸾）：沙盘铺沙，正副鸾生扶丁字形桃木乩笔，乩笔先自行颤动（乩动），再在沙上书写。
  变爻记法用六爻纳甲的通行记号：老阳“○”（重）、老阴“×”（交）。
- 画面：沙盘（双框木边、细沙纹理）淡入；俯视的 Y 形乩笔从右上移入、悬空画圈颤动，降笔时一圈光点；
  然后在沙上自下而上划出六道沟（阴爻中间提笔），变爻旁补画 ○ 或 ×；写完提笔离去，沙上的卦就是揭晓的卦，
  右侧乩示卦名、卦辞。
- 点阵：已写的爻 + 笔尖位置；乩动时一个跑圈的点。

## o.luopan 罗盘
- 依据：风水罗盘：方形地盘承圆形天盘，中央天池磁针，外层后天八卦与二十四山刻度，天心十道十字线。
  磁针南端为箭头（传统图南在上）。动爻用梅花易数取爻法：上下卦先天数之和除六取余。
- 画面：罗盘由内向外长出，磁针晃动后定于子午；天盘两度旋转（转动中右侧滚动显示经过的卦名），
  停盘时顶上指标闪光，右侧写“上卦 ☲ 离·南”“下卦 ☵ 坎·北”；揭晓时罗盘缩小到右上角。
- 点阵：转动时一根旋转指针；停下时显示所得三爻卦。

## o.cezi 测字
- 依据：《梅花易数·卷一》一字占：“如楷书，则取其字画……居左者看几数，取为上卦；居右者看几数，取为下卦。
  又以一字之阴阳，全画取爻。”本作简化为：字的左右两部分（简体）笔画数各除八取余定上下卦（先天数），全字笔画除六取余为动爻。
  字库：明、林、好、和、信、福、禄、静、清、神、仙、时、炉、松、卦、悟、根、缘、证、情。
- 画面：竖幅宣纸从中间上下展开（两根轴）；毛笔（笔杆随笔尖走）三倍大写出一个字；一刀从上划到下，字分成左右两半；
  两半下面数笔画，右侧写“上四 ☳ 震”“下三 ☲ 离”“共七画”“一爻动”；揭晓时字淡出。
- 点阵：8px 字形逐行写出 → 左右分开 → 上卦 → 下卦。

## o.guijia 龟卜
- 依据：商周龟卜：腹甲背面施钻凿，以荆木（楚焞）灼钻处，正面爆出“卜”形兆纹（兆干 + 兆枝），“卜”字即象其形。
  爻的判法是本作约定：兆枝一道直出为阳，枝分两岔为阴，再生碎纹为变；底层用三钱法概率。
- 画面：龟腹甲（千里路中缝、虚线盾纹）从右滑入，十二个钻凿依次凿出；荆木火炬（火苗 + 青烟）沿中缝两侧自下而上逐一灼烧，
  钻窝闪红，“啪”一圈白光，裂出卜形兆纹，弹出“少阳”等标签；左边卦象长出；右侧竖排“灼龟观兆”。
- 点阵：爆裂瞬间显示“卜”字形（阳一枝、阴两岔，亮度 6），其余时候显示已成之爻，灼烧时底行跑点。

## s.boot 开坛
- 依据：周敦颐《太极图说》“无极而太极”；先天八卦盘。
- 画面（3.6 秒）：黑暗中一点闪烁 → 化为一圈（无极）→ 太极自圈中旋生、减速 → 先天八卦八个卦自屏外逐一飞入落位成盘，
  外围二十四点环收拢、加一道实线圈 → 金光一闪（十六道放射线 + 扩散点环，点阵亮度 8）→ 盘移到左侧慢转，
  右侧打出“dao timer”、一道横线、“境界 练气”（`ctx.realm()`）、“道行 3”（`ctx.completed`），右下角落一枚“道”字朱印。
- 点阵：一点闪烁 → 旋转太极。

## s.reset 天地重开
- 依据：《道德经》二十五章“有物混成，先天地生”；《三五历纪》“天地混沌如鸡子……阳清为天，阴浊为地”。
- 画面（5.8 秒）：白光满屏（清零）溶开 → 混沌：110 个气点卷成三臂漩涡，底部“有物混成” → 漩涡散开，
  一半气点轻清上升（左上“阳清为天”），一半重浊下沉（右下“阴浊为地”），地面抖动灰度逐渐加深、隆起成群山 →
  一道横光自左至右劈过（点阵亮度 8）→ 天上星辰闪烁、两朵流云、新月落下，中央毛笔两倍大写出“天地重开”。
- 点阵：随机噪点（混沌）→ 上半渐稀、下半渐满 → 上方几颗星、下方实心大地。
