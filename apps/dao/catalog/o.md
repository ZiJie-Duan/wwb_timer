# 起卦（o）与特殊场景（s.boot / s.reset）——像素风

共用：`omens/o_common.py`
- `Stage`（起卦与特殊场景共用）：`tick` 算 dt、`hit` 一次性事件（落地、爆裂）、`Sparks`/`Puffs` 粒子与 `impact`（火星 + 两团尘）、
  文字队列 `say` / `say_v` / `pop` / `clear` → `flush` 在一帧最后统一画（先铺黑底板，字不被任何东西压住）。
- `Base`（起卦基类）：`init()` 里覆盖 `self.lines`；`reveal()` 统一揭晓版式。
- 小道士的自定义手臂 `arm("toss" 抛 / "hold" 托 / "reach" 前下伸 / "lift" 前伸上举)`；地面 `floor(stone/tile/earth)`；
  左上角“卦牌” `tally`（已成之爻，新爻一闪）；`rotated` 道具翻滚（按 15° 缓存）。
- `omens/o_data.py`：六十四卦卦辞摘句、先天八卦数。

统一版式：侧视小舞台，地面线 y=58，小道士在左（x≈20），道具在右。逐爻成卦的场景把已成之爻记在左上角卦牌、点阵同步。
**揭晓**（最后 2 秒）：闪白一帧 + 震屏，背景道具退场（地上的道具可留），大卦象一爻一爻从上方砸下（x 38–64，爻落处迸火星，
变爻右侧小菱形闪烁），右边打出 `full_name`（如“震为雷”）与 8px“第几卦”，顶行打出卦辞摘句、下面一道虚线；
小道士拱手 / 举手欢呼 / 作揖；点阵 `mx_hexagram`，砸落期间亮度 6。

卦辞：依《周易》通行本（王弼本）经文，每卦取首句或最有名的一句，连续原文、不增字，按 12px 一行 ≤ 10 字截取。
震卦首句“震来虩虩”的“虩”字库缺字，改取同卦辞“震惊百里，不丧匕鬯”。

## o.coins 金钱课（约 7.8 秒）
- 依据：火珠林法（三钱法）。三枚方孔钱，一背为单（少阳 7）、两背为拆（少阴 8）、三背为重（老阳 9）、三字为交（老阴 6）。
- 画面：远山一线、右边一棵松。小道士双手合拢摇钱（手上下抖、两侧声线）→ 换“抛”手一扬，三枚 13×13 方孔钱
  （字面亮、四字暗笔画；背面钱肉网点、内郭亮）在空中翻转（正面→缩窄→侧棱→背面）划弧落地，落地压扁、弹两下、
  火星与尘、震屏；弹出“单·少阳”标签，卦牌长一爻；下一掷开始时钱带虚线拖尾飞回手里。第六掷抛得最高，落地闪白。
- 点阵：已成之爻；摇钱时底行三点跳动，钱在空中时顶行跑点，落地亮一下。

## o.jiaobei 掷筊（约 7.8 秒）
- 依据：台闽庙宇的掷筊（博杯）。筊杯新月形，一面平一面凸：一平一凸为圣筊，两平为笑筊，两凸为阴筊（怒杯）。
  资料：[cmoney 筊象说明](https://www.cmoney.tw/notes/note-detail.aspx?nid=106819)、[uptogo](https://uptogo.com.tw/命理/怎麼問神？/)。
- 映射（本作的游戏化约定，非传统）：笑筊 = 老阳 9，阴筊 = 老阴 6，圣筊：左筊平面朝上 = 少阳 7，右筊平面朝上 = 少阴 8。
- 画面：庙内，顶上一盏摇晃的灯笼，右边神龛（歇山顶、牌位、供台）。小道士俯身拾起一对筊，合捧成一轮满月，额前一拜，
  扬手掷出；两只 19×8 的半月形木筊（木纹、刻线、背光网点）在空中翻滚——平面朝上的那只凸面着地前后摇晃、越摇越小，
  凸面朝上的那只“咚”地趴稳小弹一下；火星、尘、震屏，弹出“圣筊·少阳”等；下一掷前筊飞回手里。
- 点阵：已成之爻 + 底行两块筊（平面朝上一横、凸面朝上一点）。

## o.qian 求签（约 7.1 秒）
- 依据：庙宇求签。用“六十四卦签”的做法：签号 1–64 即文王卦序，只出本卦，无变爻。
- 画面：背墙冰裂纹圆窗。小道士跪在蒲团上先一拜，捧起签筒（竹节、签纸、背光网点）前倾摇动，签条哗哗抖动、声线，
  其中一支越探越高、签头闪光；最后猛一顿，那支签跳出翻滚落地弹两下（火星、震屏）；小道士放下签筒，
  签子带灵光立起、放大成一支大签（漆头网点、刻字框），签身竖刻签号（如“十八”），一圈光点旋转，小道士叩首。
- 点阵：前倾摇动的签筒（被摇出的签冒头）→ 落地的签 → 一支竖签。

## o.meihua 观梅占（约 7.7 秒）
- 依据：《梅花易数·卷一》“观梅占”（邵雍见二雀争枝坠地而起卦）与“年月日时起例”：年月日为上卦，年月日加时总数为下卦，
  总数除六取动爻；子年一数……亥年十二数，时同；先天数乾一兑二离三震四巽五坎六艮七坤八。
  原文：[维基文库 梅花易数/卷一](https://zh.wikisource.org/wiki/梅花易數/卷一)。
- 取上位机本地时间；**月、日用公历数代替农历**（没有农历表），年按公历年份取干支（立春/春节前后会差一年）。
  同一时辰内起出的卦相同（这是梅花易数的本义）。
- 画面：老梅虬干（树皮纹、背光网点）横枝伸向左上，五瓣梅花与花苞随风微颤，花瓣飘落；小道士盘坐树下赏梅。
  两只麻雀（16×13，背羽网点、颊纹、三帧扑翅）从右上飞来落枝，相向跳斗、扑翅互啄（枝条颤动、花瓣大落），
  翻滚着坠地：火星、尘、震屏，小道士吓得一蹦；麻雀愣了一下惊飞。小道士剑指掐算：左上写出“丙午年 子时”与 `7+10+25+1`，
  再写“上乾 下兑”并画出两个三爻卦。
- 点阵：一朵梅花（坠地时花心闪）→ 上卦 / 下卦交替。

## o.dayan 大衍筮（约 7.6 秒）
- 依据：《周易·系辞上》“大衍之数五十，其用四十有九。分而为二以象两，挂一以象三，揲之以四以象四时，归奇于扐以象闰。”
  三变成一爻：每变去 挂一 + 两把余数，三变后剩 36/32/28/24，除四得 9/8/7/6。十八变成卦（按真实算法用 rng 分二，
  分把用正态分布模拟手分）。
- 画面：小道士盘坐几案（牙板云头、弯腿）前。第一变逐步演示，顶上逐句打出系辞原句：五十根蓍草一根根立起；
  第五十根化作灵光飞入卦牌（太极不用）；剑指一划分成两把；右把取一根挂到手上；两把四根一组依次“啪”地跳一下（数过）；
  余数飞回手里（归奇），右上角写 `49-5=44`；四根一组的那些收拢成一把。其余十七变快进：每变末尾几根跳起消失，
  右上角算式滚动，每三变成一爻，卦牌长一爻，弹出“九·老阳”等。
- 点阵：已成之爻 + 底行余数长度条。

## o.fuji 扶乩（约 7.4 秒）
- 依据：扶乩（扶鸾）：沙盘铺沙，正副鸾生扶 Y 形桃木乩笔，乩笔先自行颤动（乩动），再在沙上书写。
  本作小道士扶一岔，另一岔灵光缭绕、无人自起（仙真扶鸾）。变爻记法用六爻纳甲的通行记号：老阳“○”（重）、老阴“×”（交）。
- 画面：梯形沙盘（俯视略斜：木框四角包铜、细沙点、前沿木板侧面网点、架子）。小道士作揖，扶起乩笔，
  乩笔在沙上空打圈、越转越急，全身发抖；“降笔”闪白、一圈光点、震屏；然后在沙上自下而上划出六道沟
  （阴爻中间提笔），沙粒四溅，每一笔落下一点火星；变爻旁补画 ○ 或 ×；写完提笔离去。
  揭晓时沙上的卦就是卦象（不再砸落），右侧竖排乩示卦名，顶行卦辞。
- 点阵：已写的爻 + 笔尖位置（底行）；乩动时一个跑圈的点。

## o.luopan 罗盘（约 7.2 秒）
- 依据：风水罗盘：方形地盘承圆形天盘，中央天池磁针，外层后天八卦与二十四山刻度，天心十道十字线。
  磁针南端为箭头（传统图南在上）。动爻用梅花易数取爻法：上下卦先天数之和除六取余。
- 画面：一面大罗盘弹出（地盘双线框、四角云头角花与铜钉，天盘双圈、二十四山刻度、后天八卦、天池、十字虚线、顶上指标），
  磁针先乱转再晃定子午；小道士剑指一拨，天盘飞转（边缘火星、速度弧），越转越慢“咔”地停住：震屏、指标闪光，
  左上写“上巽”并画出三爻卦；再拨一次得“下艮”。揭晓时罗盘缩小飞回小道士手里（9×9 小罗盘）。
- 点阵：转动时一根旋转的指针；停下时显示所得三爻卦。

## o.cezi 测字（约 6.9 秒）
- 依据：《梅花易数·卷一》一字占：“如楷书，则取其字画……居左者看几数，取为上卦；居右者看几数，取为下卦。
  又以一字之阴阳，全画取爻。”本作简化为：字的左右两部分（简体）笔画数各除八取余定上下卦（先天数），全字笔画除六取余为动爻。
  字库：明、林、好、和、信、福、禄、静、清、神、仙、时、炉、松、卦、悟、根、缘、证、情。
- 画面：一幅立轴（天杆、地杆、轴头）从上往下展开；小道士抡起一支大笔，笔头跟着笔尖走，自上而下写出三倍大的字，
  墨点飞溅；换剑指，一道剑光自上而下劈过纸面：闪白、震屏、一串火星，字分成左右两半弹开；
  两半下面先后弹出笔画数（“三”“八”）；右边写出“上离”“下坤”并弹出三爻卦。揭晓时立轴卷起。
- 点阵：8px 字形逐行写出 → 左右分开 → 上卦 → 下卦。

## o.guijia 龟卜（约 7.2 秒）
- 依据：商周龟卜：腹甲背面施钻凿，以荆木（楚焞）灼钻处，正面爆出“卜”形兆纹（兆干 + 兆枝），“卜”字即象其形。
  爻的判法是本作约定：兆枝一道直出为阳，枝分两岔为阴，再生碎纹为变；底层用三钱法概率。
- 画面：龟腹甲（暗底亮线：双线甲缘、千里路、五道盾纹、甲桥背光网点）立在木架上从右滑入，六个钻凿（钻窝 + 凿口）；
  小道士举起荆条，火苗窜起；举着燃烧的荆条（逐帧火苗）依次去灼：钻窝烧红闪烁、青烟直冒，“啪”一圈白光炸开、
  震屏、火星四溅，裂出亮的卜形兆纹，左上弹出“少阳”等，卦牌长一爻。
- 点阵：爆裂瞬间显示“卜”字形（阳一枝、阴两岔，亮度 6），灼烧时底行跑点，其余时候显示已成之爻。

## s.boot 开坛（3.5 秒）
- 画面：夜空星点、远山一线。小道士踩一朵祥云（三个云头、两个回卷、云尾网点）从左边飞来，身后拖一串灵光；
  到场一跃而下，单膝落地：闪白（点阵亮度 8）、震屏、两团尘、火星四溅、地面冲击波；祥云飘走。
  起身拱手，身后一轮光环（十六道放射线）缓转。右边“dao timer”一个字母一个字母砸下（每个落点一粒火星），
  双横线划出，打出“境界 练气”（`ctx.realm()`）、“道行 3”（`ctx.completed`）；小道士作揖，右下角一枚“道”字印从大到小“啪”地盖下。
- 点阵：一点闪烁 → 落地一圈扩散 → 旋转太极。

## s.reset 天地重开（5.6 秒）
- 依据：《道德经》二十五章“有物混成，先天地生”；《三五历纪》“天地混沌如鸡子，盘古生其中……阳清为天，阴浊为地”。
- 画面：白光满屏（清零），中间一只大蛋（双线蛋壳）显出、白光褪去 → 混沌：蛋里七十个气点打着旋，小道士低头蜷坐酣睡
  （冒鼾泡），左右竖排“有物混成”“先天地生” → 惊醒一蹦，蛋身发抖、气旋加急，抽出一柄大斧高举 →
  一斧劈下：一道横光、闪白、狂震、裂纹横贯（点阵亮度 8）；蛋分上下，上半飞升、轻清之气上升化作星斗，
  下半下沉、重浊之气落下，群山自下隆起；小道士落地双手撑天（盘古），左右竖排“阳清为天”“阴浊为地” →
  星辰闪烁、两朵祥云飘过，顶上两倍大的毛笔字写出“天地重开”，两侧小星闪，小道士作揖。
- 点阵：随机噪点褪去 → 混沌噪点翻涌 → 上半渐稀、下半渐满 → 上方几颗星、下方实心大地。
