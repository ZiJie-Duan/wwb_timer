# r1 香火·供奉·科仪（法事 9 个，像素风）

代码：`apps/dao/rituals/r1_*.py`。画风与 `r0_incense.py` 一致：逐像素精灵（黑边）、规则网点、Q 版小道士主演。
`r1_common.py` 是本批共用的零件（不登记场景）：逐像素手画的五个角度宽袖手臂 `arm(-60/-30/0/30/60)` 与
`pose_arm()`（小道士 + 任意角度的手）、`hold_at`（道具贴在手上）、`Clock`（dt）、`hit`（一次性触发）、
计数牌 `badge`、圆满大字 `title`（可放大）、闪星 `star / twinkles`、点状圆弧 `ring_dots`、点阵小工具。
已有的 `r.incense`（插香燃香）不重复。九个场景九种舞台：夜殿、院子、神龛、露天醮坛、经堂、钟楼、清晨坛场、金炉院、中元江边。

## r1.lamp 长明灯
- 依据：宫观殿前供长明灯，属五供（香、花、灯、水、果）中的灯，昼夜不熄、随时添油挑芯；灯芯结“灯花”爆开，
  旧俗以为吉兆。圆满句“薪尽火传”出自《庄子·养生主》“指穷于为薪，火传也，不知其尽也”。
  五供见[汉典“五供”](https://www.zdic.net/hans/五供)。
- 舞台：夜殿（梁、柱、月洞窗，窗外月牙和梅枝），莲花灯台上一只琉璃盏（联珠口沿、透明盏身、网点灯油、浮芯），
  身后地上一口油缸插着竹油提。
- 入场：小道士举着点着的引火棒走来，伸棒点芯，火“噗”地窜起、震屏、火星迸出，光晕一圈圈亮开；拱手作揖。
- 持续：一轮 600 秒，灯油随 e 变浅、火随油面下沉，油快尽时火变小。火苗逐帧跳，光晕呼吸旋转，偶尔爆一点灯花。
  每 36 秒：灯挑挑芯（灯花“啪”地爆开、小道士笑）；作揖；月洞窗外起风（梅枝乱摇、落叶卷进来、火被吹歪），
  小道士剑指一点，竹帘“唰”地落下挡风。飞蛾每 47 秒来绕灯。
  续：小道士转身从油缸里舀油，走到灯前举油提倒油，油面回升、火被托起，走回插好油提，“第几盏”加一。
- 中断 / 恢复 / 圆满：灯挑压低灯芯，火缩成豆火，牌子“微明”（长明灯不灭）/ 剑指一点，火星飞去，豆火窜回、闪白 /
  灯焰暴涨、放射光转动，小道士跪拜，闪白火星，“薪尽火传”。
- 点阵：灯盏 + 跳动的火（油多时盏里亮满，风吹时火歪）。

## r1.flower 散花
- 依据：全真道度亡科仪里的“散花”，用百花的荣枯比拟人生盛衰，借此化解冤结、加以劝化
  （[香港道教音乐资料](https://www.daoistmusichk.org/sites/default/files/2017-07/%E5%AE%A3%E5%82%B3%E5%B0%8F%E5%86%8A%E5%AD%90_%E5%AE%9A%E6%9C%AC_2017.pdf)）。
  《散花偈》每段以“散一朵”起句：是水仙、状元红、金海棠、风入松、是绣球、是垂杨、是雪梨、是金钱、是芙蓉、
  菊花新、是紫荆（青松观陈耀庭注本，见 [Gatha of Scattering the Flowers](https://edwardw.bearblog.dev/gatha-of-scattering-the-flowers/)）。
  圆满句“香花供养”是斋醮供养常用语。
- 舞台：院子（瓦檐矮墙、小方花窗、祥云飘），地上一只编织花篮（提梁、篮口露出的花随 e 变少）。
- 入场：小道士提着花篮走进来放下，篮里一朵朵冒出花（闪光），拱手作揖。左上牌子是花名。
- 持续：一轮 660 秒 = 十一段，每段 60 秒：伸手进篮拈花 → 蓄力 → 一抛，花苞沿弧线飞上半空“嘭”地盛开
  （23×23 逐像素花，每段一种：水仙副冠、状元红重瓣、海棠圆瓣、风入松针叶加松果、绣球、垂杨柳丝、梨花长蕊、
  金钱花方孔钱花心、芙蓉宽瓣、菊花两层细瓣、紫荆窄瓣），开着轻轻转、四周闪星；十几秒后花瓣一片片离开、
  打旋飘落，落地铺成花毯（随 e 变厚）。第 20、40 秒抓一把花瓣往前撒；作揖；每 40 秒一只蝴蝶飞来停在花篮上。
  续：一股旋风（漏斗风纹 + 盘旋花瓣）把花毯卷走，篮里的花一朵朵重新冒出来。
- 中断 / 恢复 / 圆满：半空的花合拢成苞落回篮里，牌子“收花”/ 再拈一朵抛上去重开 /
  整篮花往天上一扬，十一朵在半空排成一道弧一齐盛开，满屏花雨，闪白，“香花供养”。
- 点阵：花篮；花在半空时先是苞再开成四面花瓣，花心闪烁。

## r1.fruit 供果
- 依据：五供之果，道教又称“五献”；汉典引道士语“五献皆圆满，奉上众真前”（[汉典](https://www.zdic.net/hans/五供)）。
  供果常用桃（寿）、橘（吉），码成塔形。也参考[香港记忆：三元宫供果](https://www.hkmemory.hk/collections/ichhk/All_Items/images/201902/t20190208_90344.html)。
- 舞台：神龛（波浪边帐幔、流苏轻摆），供桌（回纹桌围、两只烛台），桌上高脚果盘；小道士身后地上一只果篮。
- 入场：高脚果盘“咚”地落到桌上弹两下；小道士提着果篮走来放下，拱手作揖。
- 持续：一轮 600 秒，每 60 秒放一颗：转身从篮里拿果 → 托在掌上走到桌前 → 举手一送，果子沿弧线跳上果塔，
  落下压扁一弹、迸火星 → 拱手 → 走回。底四、三、二，塔尖是带叶寿桃，共十颗（逐像素寿桃、蜜橘，桃橘由 seed 定）。
  每段里一只麻雀跳上桌角啄啄脑袋想偷果，小道士吃一惊，剑指一点，麻雀扑棱棱飞走；作揖。供满后塔尖闪星。
  续：神明享供——果子从塔尖起一颗颗缩小、化作光点升起，小道士跪拜，“第几盘”加一，再从第一颗放起。
- 中断 / 恢复 / 圆满：竹骨纱罩从上方落下罩住果塔（弹两下），牌子“暂歇”/ 纱罩被提起飞走 /
  没放满的果子一颗接一颗从篮里跳上去补齐，塔尖放光，小道士跪拜，闪白，“五献皆圆满”。
- 点阵：盘 + 果塔，最新一颗闪；罩上纱罩时外圈框起。

## r1.wine 三献酒
- 依据：祭礼三献（初献、亚献、终献），道教斋醮献供亦行三献；“酹”是把酒浇在地上致祭；
  “爵”是三足、双柱、前流后尾、侧有鋬的古酒器。礼毕赞“礼成”。
- 舞台：露天醮坛（远山虚线、两杆长幡迎风飘），矮供案（卷云纹案裙）上三只青铜爵，左边小几上一把长流执壶。
- 入场：三只爵依次从天上落到案上“当”地弹一下站稳；小道士走来，拱手作揖。左上牌子“第一巡 初献”。
- 持续：一轮 600 秒分三献（第 10、200、400 秒）：转身提壶 → 走到爵前 → 举壶前倾，酒线注入、溅起酒花，
  爵口亮起酒面 → 走回放壶 → 对爵作揖。斟满的爵口飘一缕酒香。长幡一直飘，隔一阵起风猛地扬起；
  每 45 秒一只仙鹤扇着翅膀飞过远山。
  续：酹酒——小道士捧起中间那只爵走到坛前，爵口朝下把酒浇在地上，溅起酒花、地上一摊酒；
  另两爵的酒化作光点升空，“第几巡”加一，再从初献斟起。
- 中断 / 恢复 / 圆满：拱手肃立、酒香散尽，“暂歇”/ 作揖、酒香复起 / 三爵斟满齐放光，小道士跪拜，
  闪白，放大字“礼成”。
- 点阵：爵的图标，爵身随斟满的爵数亮起；倒酒时顶上闪一点酒滴。

## r1.memorial 焚表
- 依据：斋醮中的拜表（进表）、封表，焚化表文以达天庭；表文自右而左竖写，常用程式语“伏以”
  “诚惶诚恐，稽首顿首”，结尾“谨表以闻”；“道经师宝”是道教法印的印文。参见
  [daoinfo：Rituals for Sending Petitions to the Heavens](https://en.daoinfo.org/wiki/Rituals_for_Sending_Petitions_to_the_Heavens)。
- 舞台：经堂（右边一排经柜格子、左边烛台），中间一架表屏（横杆、宝珠顶立柱）挂着一幅白表（双线边框）。
- 入场：表从横杆上“唰”地垂下展开（弹一下）；小道士执大笔走来，笔尖一点，墨星一闪。
- 持续：一轮 600 秒写二十字（四行每行五字，自右而左、自上而下，黑墨写在白表上）：每写一行往左挪一步，
  按字的高低举手 / 斜举 / 平伸，笔尖一笔一笔点出字形（逐像素显现、笔尖微颤），写完收笔迸墨星；
  隔一阵对着墨迹吹一口气（嘟嘴、气流），或者拱手作揖。烛火跳动。
  续：举起法印“咚”地钤在表尾（道经师宝），表从下往上焚化（火舌沿焦边、纸灰烟团、火星往上飘），
  小道士跪拜；烧尽后横杆上垂下一幅新表，“第几表”加一。
- 中断 / 恢复 / 圆满：笔挂到表屏的笔钩上，拱手，“停笔”/ 取下笔，笔尖一点，闪白 /
  钤印，整幅表燃起金火，纸灰化作一只仙鹤扇着翅膀飞走，小道士跪拜，闪白，“谨表以闻”。
- 点阵：四列对应表上四行，写好的字点亮，正在写的那个字闪烁；焚化时是一团往上蹿的火。

## r1.bell 鸣钟
- 依据：宫观“金钟玉磬”，钟用来集众、动神（[daoinfo：Bells](https://en.daoinfo.org/wiki/Bells)，引《太真科》）；
  寺观撞钟通行一百零八下：“紧十八，慢十八，不紧不慢又十八”，两遍合成一百零八
  （[搜狐：寺庙撞钟的意义和规矩](https://www.sohu.com/a/213979662_671412)）；道观以钟板“开静”“止静”。
  圆满句出自《度人经》“琳琅振响，十方肃清”。
- 舞台：钟楼（横梁、立柱、柱础），梁上挂一口铜钟（蒲牢钮、乳钉三排、弦纹、莲花撞座、波浪钟口），
  左边两根绳吊着撞木（铁箍、木纹），梁头停着一只小鸟。
- 入场：大钟从梁上落下晃两下，撞木荡进来；小道士走来拉住绳，牌子“起钟”。
- 持续：一轮 600 秒：开头 6 秒“起钟”（拱手作揖、把撞木拉满），随后两遍（紧杵 3 秒 / 慢杵 8 秒 / 平杵 5 秒，
  各十八杵）共一百零八响，每一杵的时刻完全由 e 算出。小道士拉绳把撞木往后拽（身子后仰，间隔越长拉得越开），
  一松手撞木荡回去“咚”——钟身一震一晃、声波弧一圈圈荡开、震屏、点阵一闪，梁上小鸟吓得一跳。
  牌子写节奏与响数（如“慢杵 二十四”）。一百零八响后十几秒“余音”，钟慢慢停摆，小道士拱手。
- 中断 / 恢复 / 圆满：撞木停稳，牌子“止静”/“开静”，拉开一撞，接上原来的节奏 /
  连撞三记重杵（钟身发亮、声波满屏），小道士跪拜，闪白，“琳琅振响”。
- 点阵：钟形图标；撞的那一下高亮、左右一震，钟口下荡出一道波。

## r1.sprinkle 洒净
- 依据：开坛先洒净荡秽，高功用柳枝（杨枝）蘸净水洒坛，同时诵《净天地神咒》
  （“天地自然，秽炁分散……凶秽消散，道炁长存。急急如律令”）。字库没有“炁”，用“气”代替。
- 舞台：清晨坛场（朝阳光芒慢转、一道远山、两根望柱），坛中盂架上一只净水盂（卷沿、缠枝纹）。
- 入场：净水盂“咚”地落到盂架上，水面一圈涟漪；小道士举着柳枝走来，柳叶一颤。
- 持续：每 6 秒一个动作：柳梢点进盂里（水面涟漪）→ 提起（梢头滴水）→ 举过头蓄力 → 一甩（挥动弧线），
  十一颗水珠呈扇形飞出、沿抛物线落下，飞到最高点一闪，落地溅起水花；每甩四次绕到盂的另一边换方向洒。
  一轮 600 秒念完全咒二十二句（左上牌子一句一句换）；柳叶随 e 越来越少，隔一阵飘落一片。
  续：天上落下三滴甘露“叮”地注进盂里（涟漪），柳枝重新抽出满枝新叶。
- 中断 / 恢复 / 圆满：柳枝横搁在盂沿上，拱手，“暂歇”/ 拿起柳枝蘸水一甩 /
  举柳枝原地一转，水珠向四面八方洒开，地平线上挂起一道彩虹（三道点弧），小道士跪拜，闪白，“急急如律令”。
- 点阵：底下是净水盂，一甩时三颗水珠飞起再落下；甘露时一道细流落下。

## r1.joss 化宝
- 依据：宫观设金炉（化宝炉）专门焚化金银纸、元宝、疏文；“填还受生”科仪焚化受生钱，以填还本命天库。
- 舞台：夜里的院子（瓦檐墙、几颗星），右边一座砖砌金炉（葫芦顶、攒尖顶翘角、出烟小龛、腰檐、砖缝、
  拱形炉口里火苗逐帧跳、须弥座），左边地上一堆纸元宝（逐像素元宝，金字塔码放）。
- 入场：金炉从地下升起（震屏），炉膛“轰”地点着、火星喷出；元宝一锭锭从天上落下弹跳着码成堆；小道士走来拱手。
- 持续：一轮 600 秒四十锭（元宝堆一层层变矮）：每 15 秒转身拿一锭 → 举手一抛，元宝打着旋、带金光拖尾
  飞进炉口 → 火舌窜出炉口、炉顶喷火星冒烟团、震屏。中间穿插：拿火钳捅炉膛（火一窜）、
  一颗火星蹦到脚边把小道士吓得一跳、作揖。炉顶一直冒烟、飘火星。
  续：新元宝一锭接一锭从天上落下码回一堆，小道士举手接、拱手，“第几炉”加一。
- 中断 / 恢复 / 圆满：两扇带门钉的炉门合上（震一下），只剩门缝一线火光，“封炉”/ 剑指一点，
  炉门打开，火“轰”地一窜、闪白 / 剩下的元宝一锭接一锭飞进炉里，炉顶火柱冲天、火星喷涌，小道士跪拜，
  闪白，“填还受生”。
- 点阵：底下是炉座，上面跳动的火柱，窜火时火柱变高；封炉时只剩门缝一点。

## r1.river 放河灯
- 依据：农历七月十五中元节，道经以为“地官赦罪”之日，宫观设中元普度；当夜放水灯（河灯、荷花灯），
  中元也有烧法船的习俗（[中国非遗网：中元节](https://www.ihchina.cn/project_details/9857.html)）。七月十五是满月。
- 舞台：中元夜（满月带暗斑、星星、远山剪影），江面水纹缓缓横移、月影碎成一串，前景左下是江边石阶，
  阶上一只灯篮。
- 入场：夜色渐显，江心荡开几圈涟漪；小道士走到石阶上，对江拱手作揖。
- 持续：每 60 秒放一盏（一轮十盏 = 600 秒）：转身从灯篮取灯 → 跪下 → 送灯入水（涟漪一圈圈、水花）→ 起身作揖。
  每盏用 300 秒漂到天边，越漂越小越高（近处是逐像素莲花灯 + 跳动火苗 + 碎光倒影，远了变小灯、光点），
  同时漂着五盏、分三条航道。每 41 秒一条鱼跃出水面“扑通”溅起水花，萤火虫一闪一闪；作揖。
  续：远处一只纸扎法船（两层楼、风帆、窗里亮灯）从左到右驶过天边，“第几盏”从头数起。
- 中断 / 恢复 / 圆满：江雾（点状雾带）从两岸往江心漫，灯火暗成一点，“暂歇”/ 剑指一点，雾散，
  灯火一盏盏复明（火星、闪白）/ 每盏灯的火光离开灯升空化作星点，满月放光，小道士跪拜，闪白，“中元普度”。
- 点阵：一盏莲花灯，火苗跳动，底下一行水波流动。
