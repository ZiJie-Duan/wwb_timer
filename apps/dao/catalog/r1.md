# r1 香火·供奉·科仪（法事 9 个）

代码：`apps/dao/rituals/r1_*.py`（`r1_common.py` 是本批共用的小零件：宽袖手臂 `sleeve`、竖排渐显 `vreveal`、
闪光 `sparkles`、放射线 `rays`、点状圆弧 `arc_dots`、点阵圆环 `mx_ring`，不登记场景）。
已有的 `r.incense`（插香燃香）不重复。九个场景的主体分别是：琉璃灯、花篮散花、果塔、青铜爵、黄表、大钟、
柳枝净水盂、金炉、江面河灯。

## r1.lamp 长明灯
- 依据：宫观殿前供长明灯，属五供（香、花、灯、水、果）中的灯，昼夜不熄、随时添油；收尾句出自《庄子·养生主》
  “指穷于为薪，火传也，不知其尽也”。五供见[汉典“五供”](https://www.zdic.net/hans/五供)。
- 入场：宽袖手执引火棒从左下伸来，点着琉璃盏里的浮芯，一圈闪光，光晕一层层亮开；左“长明灯”、右“第一盏”。
- 持续：一轮 600 秒。灯油随 e 慢慢变浅（盏里的抖动灰度），浮芯和火苗跟着油面下沉，油快尽时火变小；光晕呼吸，
  每 23 秒一只飞蛾绕灯飞一圈。续：右上方一只手提油壶倾倒，油线注入，油面回升，火苗被托起，“第几盏”加一。
- 中断 / 恢复 / 圆满：捻小灯芯，火缩成一粒豆火、光晕收拢，右侧“微火”（长明灯不熄）/ 豆火长回原样，光晕再起 /
  灯焰暴涨，上半圈放射光与闪星，“火传也 / 不知其尽也”。
- 点阵：小灯盏，火苗跳动；油多时盏里亮一行。

## r1.flower 散花
- 依据：全真道度亡科仪里的“散花”，用百花的荣枯比拟人生盛衰，借此化解亡灵冤结、加以劝化
  （[香港道教音乐资料](https://www.daoistmusichk.org/sites/default/files/2017-07/%E5%AE%A3%E5%82%B3%E5%B0%8F%E5%86%8A%E5%AD%90_%E5%AE%9A%E6%9C%AC_2017.pdf)）。
  《散花偈》每段以“散一朵”起句：是水仙、状元红、金海棠、风入松、是绣球、是垂杨、是雪梨、是金钱、是芙蓉、
  菊花新、是紫荆（青松观陈耀庭注本，见 [Gatha of Scattering the Flowers](https://edwardw.bearblog.dev/gatha-of-scattering-the-flowers/)）。
- 入场：花篮从上方落地弹两下，篮口冒出十一朵花，左侧竖写“散一朵”。
- 持续：一轮 666 秒十一段，每段 60 秒：宽袖手从右上伸进花篮拈起一朵，往上一抛，花苞飞到右上半空，
  “嘭”地盛开（每段一种花形：水仙六尖瓣带副冠、状元红重瓣、海棠五圆瓣、风入松三簇松针加松果、绣球一团小花、
  垂杨柳丝、梨花带蕊、金钱花心是一枚方孔钱、芙蓉大瓣带脉、菊花两层细瓣、紫荆窄瓣长蕊），右侧竖写这一段的花名。
  花开着轻轻转，十秒后花瓣一片片离开，打着旋儿飘落，落地后铺成花毯。篮里的花随 e 变少，地上的花瓣变多。
  续：一阵风（风纹带卷）把满地花瓣卷起吹走，篮里重新冒满花，再从“是水仙”散起。
- 中断 / 恢复 / 圆满：半空的花合拢成苞、落回篮里，飘着的花瓣一齐落地，右侧“暂歇” /
  一阵小风把几片花瓣从地上卷起又落下，接着散花 / 篮里剩下的花一齐飞出、在空中开成一片，满屏花雨，大字“散花”。
- 点阵：平时是花篮；花在半空时先是花苞，再盛开成四面花瓣，花心闪烁；落瓣时几点往下飘；最底一行是地上积的花瓣数。

## r1.fruit 供果
- 依据：五供之果，道教又称“五献”；汉典引道士语“五献皆圆满，奉上众真前”（[汉典](https://www.zdic.net/hans/五供)）。
  供果常用桃（寿）、橘（吉），码成塔形。也参考[香港记忆：三元宫供果](https://www.hkmemory.hk/collections/ichhk/All_Items/images/201902/t20190208_90344.html)。
- 入场：供桌、两只插花瓶，高脚果盘从上方落下，一只宽袖手放上第一颗果，桌围上写出“第一盘”。
- 持续：一轮 600 秒，每 54 秒手从右上伸来放一颗，落下时轻弹一下：底四、三、二，塔尖是带叶的寿桃，共十颗
  （桃、橘由 seed 决定）。花枝轻摇，每 17 秒飘落一片花瓣；供满后寿桃周围闪光。
  续：神明享供，果子从上到下缩小、化作光点升起，手再放第一颗，“第几盘”加一。
- 中断 / 恢复 / 圆满：一只网纱罩从上方落下罩住果盘（弹两下），“暂歇” / 纱罩提起离去 /
  未放满的果子补齐，塔尖放光，果子依次轻跳，桌围“五献皆圆满”。
- 点阵：果塔（每颗两点）放在盘上，最新一颗闪烁；纱罩落下时点阵外圈框起。

## r1.wine 三献酒
- 依据：祭礼三献（初献、亚献、终献），道教斋醮献供也行三献；“酹”是把酒浇在地上致祭；
  “爵”是三足、双柱、前流后尾的古酒器。
- 入场：三只青铜爵依次从上方落到供桌上弹跳站稳，左上“初献”，右上“第一巡”。
- 持续：一轮 600 秒分三献（第 3、200、400 秒）：一只宽袖手提执壶从右上飞来，悬在爵上倾倒，酒线注入，
  爵里酒面（抖动灰度）升起；斟满的爵上飘一缕酒香，酒面上有一点暗光游走。
  续：三只爵以前足为支点前倾，把酒酹在地上，地面溅起酒花，爵回正、酒空，再从初献斟起，“第几巡”加一。
- 中断 / 恢复 / 圆满：手把执壶放在供桌右端，酒香散去，“暂歇” / 手把执壶提走，酒香复起 /
  三爵齐酹，然后“礼成”（放大字）弹出，四周闪光。
- 点阵：爵的图标，酒面随斟满的爵数升高；正在倒酒时顶上闪一点酒滴。

## r1.memorial 焚表
- 依据：斋醮中的拜表（进表）、封表，焚化表文以达天庭；表文常用程式语“伏以”“诚惶诚恐，稽首顿首”
  “谨表以闻”；“道经师宝”是道教法印的印文。参见
  [daoinfo：Rituals for Sending Petitions to the Heavens](https://en.daoinfo.org/wiki/Rituals_for_Sending_Petitions_to_the_Heavens)。
- 入场：卷着的表从上方落下，两根轴向两边展开成一幅（双线边框）；宽袖手执毛笔伸进来；左“上章”、右“第一表”。
- 持续：一轮 600 秒。二十个字（伏以 / 诚惶诚恐 / 稽首顿首 / 具表上奏 / 伏乞 / 谨表以闻）自右而左、
  每字由笔尖自上而下写出（逐行显现），写完一字，笔移到下一字上方等着。笔杆角度随笔尖高低渐变，
  所以握笔的手总在画面里。写完后笔退出，一方印章落下，在“伏乞”下面钤上“道经师宝”。
  续：表从两头卷起，卷轴自下而上焚化（火舌、焦边、纸灰飘升、青烟），新的一幅再展开，“第几表”加一。
- 中断 / 恢复 / 圆满：笔收走，一根镇纸落下压住表，“停笔” / 镇纸拿走，笔回来 /
  卷表焚化，一只仙鹤从灰烟中扇着翅膀飞起，“上达天听”。
- 点阵：六列对应表上六行，写好的字点亮，正在写的那个字闪烁；钤印后左下亮一小块；焚化时是一团往上蹿的火。

## r1.bell 鸣钟
- 依据：宫观“金钟玉磬”，钟用来集众、动神（[daoinfo：Bells](https://en.daoinfo.org/wiki/Bells)，引《太真科》）；
  寺观撞钟通行一百零八下：“紧十八，慢十八，不紧不慢又十八”，两遍合成一百零八
  （[搜狐：寺庙撞钟的意义和规矩](https://www.sohu.com/a/213979662_671412)）；道观以钟板“开静”“止静”。
- 入场：大钟从上方落到梁上晃两下，用绳吊着的撞木从左边荡进来，被拉开；左下“起钟”。
- 持续：一轮 600 秒 = 两遍（紧 3 秒 / 慢 8 秒 / 不紧不慢 5 秒，各十八杵）共一百零八响。每一杵的时刻完全由 e 算出：
  撞木像钟摆一样拉开再撞回，杵距越长拉得越开；撞上那一刻钟身一震，声波弧一圈圈往外荡，点阵一闪。
  右侧竖写响数（一 … 一百零八），左下写当前节奏（紧杵、慢杵、平杵）。
  续：一百零八响后有二十多秒“余音”，撞木慢慢拉满，下一轮第一杵前写“起钟”。
- 中断 / 恢复 / 圆满：撞木停靠在钟边，余音散尽，“止静” / “开静”，撞木荡开撞一杵，接上原来的节奏 /
  连撞三记重杵，两侧声波满屏，钟身发亮，右“琳琅振响”、左“十方肃清”（《度人经》）。
- 点阵：钟形图标；撞的那一下高亮、左右一震，钟口下荡出一道波。

## r1.sprinkle 洒净
- 依据：开坛先洒净荡秽，高功用柳枝（杨枝）蘸净水洒坛，同时诵《净天地神咒》
  （“天地自然，秽炁分散……凶秽消散，道炁长存。急急如律令”）。字库没有“炁”，用“气”代替。
- 入场：净水盂落下，宽袖手执一枝垂柳从右边伸来；左侧竖写第一句“天地自然”。
- 持续：每 6 秒一个动作：柳梢点进盂里（水面起涟漪）→ 提起后拉 → 一甩，十二颗水珠呈扇形飞出、
  沿抛物线落下，飞到最高点时一闪，落地时溅起一点闪光（方向在左上、上、左之间轮换）。
  一轮 600 秒念完全咒二十二句（左侧竖排，逐字出现）；柳叶隔一阵掉一片飘到地上，盂里的水慢慢变浅。
  续：旧柳枝收走，天上落下三道甘露把盂注满，手拿来一枝叶子齐全的新柳。
- 中断 / 恢复 / 圆满：柳枝横放在盂沿上，手松开收走 / 手回来拿起柳枝 /
  蘸水后柳枝绕手一转，分六次往四面八方洒出水珠，满屏闪光，左侧“急急如律令”。
- 点阵：底下是净水盂，柳枝点水时亮一点，一甩时三颗水珠飞起再落下；甘露时一道细流落下。

## r1.joss 化宝
- 依据：宫观设金炉（化宝炉）专门焚化金银纸、元宝、疏文；“填还受生”科仪焚化受生钱，以填还本命天库。
- 入场：金炉从下方升起（须弥座、拱形炉口、“金炉”匾、两重翘角檐、葫芦顶），炉里的火轰地点着，
  左边元宝一锭锭落下码成一堆；右侧“第一炉”。
- 持续：一轮 600 秒十锭（底四、三、二、一），每 50 秒一只宽袖手从左上伸到元宝堆，拿起最上面一锭，
  沿抛物线抛进炉口；落进去时火舌窜出炉口、盖过匾额，炉顶飘出火星，点阵一亮。元宝堆随 e 变少。
  续：新元宝一锭接一锭从天上落下，弹跳着码回一堆，“第几炉”加一。
- 中断 / 恢复 / 圆满：两扇炉门（带门钉）合上，只剩门缝一线火光，“封炉” / 炉门打开，火一窜 /
  剩下的元宝一锭接一锭飞进炉里，大火冲天，火星喷涌，左上“填还受生”。
- 点阵：底下是炉座，上面跳动的火柱，窜火时火柱变高；封炉时只剩门缝一点。

## r1.river 放河灯
- 依据：农历七月十五中元节，道经以为“地官赦罪”之日，宫观设中元普度；当夜放水灯（河灯、荷花灯），
  中元也有烧法船的习俗（[中国非遗网：中元节](https://www.ihchina.cn/project_details/9857.html)）。七月十五是满月。
- 入场：夜空与满月渐显，远山、水纹铺开，一只手从画面下方托着第一盏莲花灯放进水里，荡起涟漪；
  左“地官赦罪”，右下“第一轮”。
- 持续：每 60 秒放一盏（一轮十盏 = 600 秒），每盏用 300 秒漂到天边，一路先快后慢、越来越小，
  画面上同时漂着五盏、远近大小不同，相邻两盏左右错开。火苗跳动，倒影是碎光，灯随波轻轻起伏；
  水纹缓缓横移，月影在水里碎成一串。续：远处一只纸扎法船（两层楼、两面帆、窗里有灯）从左到右驶过天边，
  “第几轮”加一。
- 中断 / 恢复 / 圆满：江雾从两岸漫来，水面和灯淡下去，灯火暗成一点，“雾锁江” / 雾散，灯火复明 /
  江上每盏灯的火光离开灯，升空化作星点闪烁，左侧“中元普度”。
- 点阵：一盏莲花灯，火苗跳动，底下一行水波流动。
