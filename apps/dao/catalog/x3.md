# x3 歇 · 山水与天象（道家的“观”）

九个歇，都是 Q 版小道士坐下来看天地：观云、听雨、观瀑、垂钓、望月、迎日、听松、观潮、观鱼。
画风：清晰的 1 位像素画（2026-10 重做，替换掉旧的灰度 / 简笔版本）。

共用工具在 `rests/x3_lib.py`：
- 山：`ridge()` 出山脊、`mountain()` 做成 Sprite。远近层次全靠“规则网点阶梯”：受光坡（往右升高）山脊下一条由浓到淡的网点带
  （50% → 25% → 12.5%），背光坡只有一窄条；远山可用隔点山脊；`cap` 画实白雪冠，`veins` 画沟壑线。
- 像素云 `cloud()`：一排圆鼓包 + 平底，白轮廓黑心（会挡住后面的山），鼓包里一道卷纹，底下一行网点；`faded()` 让精灵按有序抖动散开。
- 水：`glints()` 近大远小的碎光、`ring()` 涟漪、`splash()` 水花帧、`drops()` 斜雨丝。
- 其他：`rock()` 山石、`pine_pad()` 一簇松针（锯齿上沿 + 网点针叶 + 垂针）、`hat()` 斗笠、`ribbon()` 发带、`bird()` 三帧飞鸟、`star()` 星闪。
- 文字：`plate()` / `vplate()` 先压黑底细框再写字（最后画），保证不被画面压住。

所有 hold 只依赖 t（无逐帧状态），任何时刻都能直接画；小事件按 `every(t, 周期, 时长, 偏移)` 排定。
入场用“世界时间 t − T[enter]”画背景，最后一帧正好接上 hold(0)；退场用 `self.hold_t + t` 接着持续阶段收场。
每个场景只有一处题字（偶尔两处），放在干净处并带黑底。

## x3.cloud 坐看云起
- 依据：王维《终南别业》“行到水穷处，坐看云起时”；陶渊明《归去来兮辞》“云无心以出岫，鸟倦飞而知还”。
- 画面：小道士盘坐在左边崖头（黑剪影、岩纹、断面网点背光），远山隔点山脊、中山受光网点带夹着一道山谷；
  像素云从山谷里冒出来，小 → 中 → 大，一边升一边右飘，到高处散成点（三朵错开，一朵 33 秒）；山脚溪水碎光往左流到崖下就没了（水穷处）；崖头草叶摇动，高处一条长云缓缓横移。
- 小事件：倦鸟两只飞回远山、落进山后（47s）；一朵小云飘到跟前，小道士伸指一点，云“噗”地散成三小团、他笑（113s）；“坐看云起时”题在左上（75s）。
- 入场（3.0s）：小道士从左边走上崖头坐下，扬起一点土，山水淡入。退场（1.3s）：三排云头从山谷涌上来，把画面淹没。
- 点阵：两座小山，山谷里一团云往上冒。

## x3.rain 听雨
- 依据：温庭筠《更漏子》“一叶叶，一声声，空阶滴到明”；雨打芭蕉；《道德经》七十八章“天下莫柔弱于水，而攻坚强者莫之能胜”（滴水石上的小坑）。
- 画面：侧视檐廊：筒瓦一垄垄、檐口一排瓦当、椽头；墙上窗格、“听雨”小匾；小道士盘坐廊下，手边茶盏冒热气；廊柱、风铃、错缝条石台基。
  院子里斜雨丝一阵密一阵疏，芭蕉（假茎 + 四片带平行侧脉、有裂口的大叶）被雨打得一颤一颤；檐口水珠鼓起 → 落下 → 石上溅花漾圈；水洼涟漪；远山只剩隔点山脊。
- 小事件：端起茶盏喝一口（37s）；青蛙跳上滴水石，鼓腮叫两声再跳走（83s）；远处闪电劈下、满屏一闪，小道士吓一跳、风铃乱摇，随后雨急一阵（151s）；廊柱上蜗牛十分钟爬一趟。
- 入场（2.8s）：画面淡入，雨由疏到密，小匾落下来晃一晃。退场（1.2s）：雨渐停，淡出。
- 点阵：顶行是檐，三列水珠落下，落地溅开。

## x3.falls 观瀑
- 依据：李白《望庐山瀑布》“日照香炉生紫烟……飞流直下三千尺，疑是银河落九天”。
- 画面：两道黑色断崖（斧劈皴、受光边网点带、苔点）夹着瀑布；瀑布每一列是速度、断点各不同的滚动虚线，隔列稀密；崖口水头一道白弧；
  潭底白沫一团团鼓起、水珠抛物线四溅、水雾往上飘、潭纹往两边荡开；远处香炉峰顶飘着像素烟；崖顶一株探身松；小道士坐在潭边石上看。
- 小事件：落叶漂到崖口翻下去，在潭里打转漂走（53s）；燕子穿过水雾（71s）；水雾里三重虹从左到右画出，小道士惊喜举手（130s）；“飞流直下”竖题在右崖上（70s）。
- 入场（2.6s）：崖口先渗水，水头坠下砸进潭里，一圈水花、屏幕一震；题字逐字出现。退场（1.3s）：水断，水尾落进潭里，水雾散尽。
- 点阵：两边崖壁，中间水列往下冲，底部溅花。

## x3.snow 寒江独钓
- 依据：柳宗元《江雪》“千山鸟飞绝，万径人踪灭。孤舟蓑笠翁，独钓寒江雪”。
- 画面：远山实白雪冠、中山两侧，江面空阔、碎光稀疏；一叶小舟随波起伏、有隔点倒影；小道士戴斗笠（篾纹）、披蓑衣（草茎、参差下摆）坐在船尾垂钓；
  右岸两株压雪的松（一层层白边枝）。雪分远近三层（远的单点慢、近的十字雪花摇摆）。
- 持续：斗笠、船舷积雪慢慢堆白（150s 一轮），积满了小道士抖一抖，雪簌簌落下。
- 小事件（47s）：浮子一点一点 → 提竿：多半空钩，三成钓上一尾小鱼挂着扑腾，然后重新甩线、浮子落水漾一圈。刻意没有鸟（千山鸟飞绝）。“独钓寒江雪”题字（80s）。
- 入场（3.4s）：雪由疏到密，小舟从左边滑进来，船尾拖着水纹。退场（1.3s）：小舟划出画外、风吹雪斜，淡出。
- 点阵：雪花落下，底部积雪随斗笠积雪变厚，抖雪时清空。

## x3.moon 望月
- 依据：苏轼《水调歌头》“明月几时有”“千里共婵娟”；张九龄《望月怀远》“海上生明月”；李白《静夜思》“举头望明月”、《月下独酌》“举杯邀明月”；杜甫“月是故乡明”。
- 月相：**按真实日期算**（朔望月 29.530588853 天，以 2000-01-06 18:14 UTC 的朔为起点）。盈月亮在右、亏月亮在左；亮面几块网点月海，暗面只有隔点轮廓；亮度高时有一圈虚线月晕。
  月下标月相名：朔月 / 蛾眉月 / 上弦月 / 盈凸月 / 望月 / 亏凸月 / 下弦月 / 残月。（本批唯一读系统时钟的地方。）
- 画面：江边石矶上一座小亭（攒尖、宝顶、翘角、两柱、栏杆），小道士在亭里凭栏坐着望月；星星闪烁（偶尔亮成十字）；远山一抹；月影是一条碎银，越近越宽，亮度随月相。
- 小事件：举杯邀月（60s）；薄云从右往左掠过月面（97s）；一行雁从月前飞过（151s）；月影里跳起一尾鱼（67s）；诗句每两分钟在江面浮现一句（此时月相名让位）。
- 入场（3.0s）：月亮从远山后升起，月影铺开。退场（1.3s）：云从右边合拢，月光收尽。
- 点阵：今晚真实的月相（朔月时只留一圈虚线），角上偶有星闪。

## x3.dawn 紫气东来
- 依据：《列仙传》“老子西游，关令尹喜望见有紫气浮关，而老子果乘青牛而过也”（函谷关）。
- 画面：三层云头往左流（远小慢、近大快），群峰露出云海；西边关楼（城台砖缝、拱门洞、垛口、两重檐）门洞亮着；东边日轮升起，十二道虚线光芒长短相间、缓缓转动；
  三缕紫气是三道往西流动的波浪虚线，从日边弯进关楼；小道士站在近处山石上朝日拱手作揖。
- 小事件：日光一亮、光芒伸长（43s）；三只飞鸟掠过日前（59s）；每 300s 老子骑青牛从东边云头上走进关门，到关前小道士笑、“紫气东来”浮现。
- 入场（3.4s）：太阳从云海里升起，光芒散开，紫气伸向关楼，题“紫气东来”。退场（1.4s）：画面从西往东褪去，最后太阳收成一点。
- 点阵：底行云海，中间一轮日，光芒旋转，日光一亮时外圈变大。

## x3.pine 松风
- 依据：《梁书·陶弘景传》（《太平御览》卷九五三引）“特爱松风，庭院皆植松，每闻其响，欣然为乐”。陶弘景是茅山上清派宗师。
  出处：<https://ctext.org/taiping-yulan/953>
- 画面：崖头老松：扭转的主干（树皮鳞纹）、一枝长臂探向山谷、低枝，十簇像素松针；松下小道士盘坐听风，发带往后飘；山谷里远山、一线远瀑。
- 持续：平时微风轻摇（离根越远摆得越多）；每 31s 一阵大风（2s 起风、9s 落定）：风线（带卷头）成群从右往左掠过、松针团整排压弯、松针被吹落、发带飘平。
- 小事件：松果从长臂上掉下，在石上弹两下，小道士吓一跳；随后松鼠从树根跑出来，蹲着啃一会儿，叼起松果跑回去（73s）；两只飞鸟掠过山谷（117s）；“特爱松风”题在山谷下方（140s）。
- 入场（2.6s）：淡入，题字。退场（1.2s）：淡出，点阵波形平息。
- 点阵：“松涛”波形，振幅与速度随风势，大风时加粗。

## x3.tide 观潮
- 依据：钱塘江潮。苏轼《催试官考较戏作》“八月十八潮，壮观天下无”；潘阆《酒泉子》“弄潮儿向涛头立，手把红旗旗不湿”。
  出处：<https://cn-poetry.com/su-shi-poems/written-to-examiners.html>
- 画面：站在鱼鳞石塘（错缝条石）上隔江远望：对岸山上七层六和塔，远山一抹；江面碎光漂动。小道士站在塘上，平时偶尔手搭凉棚。
- 持续：每 75s 一潮：一线潮从右边天边斜着推过江面，越近越高越宽；潮头一道白练、上沿浪花、前面飞沫、身后一片翻涌网点；
  潮头扫到塘下浪花溅过塘顶；潮快到时小道士伸手一指，扫到面前时往后一缩、惊叫，过后笑。每潮大小不同；三成多的潮头上立着举旗的弄潮儿。
- 题句：潮来时“八月十八潮”（有弄潮儿时“弄潮儿向涛头立”），潮过后“壮观天下无”。小事件：江鸥掠过（41s）。
- 入场（2.8s）：石塘从下面升上来，题“八月十八潮”。退场（1.3s）：最后一道大浪从右边漫过整幅画面。
- 点阵：底行江岸、细浪；潮来时一道浪墙从右往左推过点阵，高度随潮的大小。

## x3.fish 濠梁观鱼
- 依据：《庄子·秋水》濠梁之辩。原文：<https://zh.wikisource.org/zh-hans/%E8%8E%8A%E5%AD%90/%E7%A7%8B%E6%B0%B4>
- 画面：濠水上一道石梁（平桥：条石桥面、两根桥墩、望柱栏杆），小道士（庄子）在左、戴冠的惠子在右；桥下清水，水面波纹逐帧流动，
  左边荷叶、荷苞，右边荷叶；水底水草摇摆、沙点；五尾鯈鱼（尖头、尾巴三帧摆动）沿各自路线从容游动，穿过桥墩后面。
- 辩论：每 9s 一句、显示 6s，庄子的话靠左、惠子的话靠右（带小尾巴指向说话的人），说话的人拱手：
  是鱼之乐也 / 子非鱼 / 安知鱼之乐 / 子非我 / 请循其本 / 我知之濠上（均取原文短句）。
- 小事件：鱼浮上来吐泡（19s）；一尾鱼跃出水面、庄子笑（43s）；落叶飘下落水，鱼都凑过去啄，叶子一颤一颤（61s）；蜻蜓落在荷苞上歇一会再飞走（89s）。
- 入场（2.6s）：石梁从上方落下来，水波渐平，鱼从四边游回来。退场（1.2s）：鱼往四面散开，水纹荡开，淡出。
- 点阵：一尾小鱼来回游，吐泡。
