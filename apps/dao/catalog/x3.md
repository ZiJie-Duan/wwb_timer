# x3 歇 · 山水与天象（道家的“观”）

九个歇，都是“坐下来看天地”：观云、观水、观雪、观月、观日、听松、听雨、观潮、观鱼。
共用工具在 `rests/x3_lib.py`（山层 Sprite、水墨云、题诗、缓存文字位图、按 t 定时的小事件、暗边像素画）。
远近层次统一画法：远山 = 稀疏抖动、虚线山脊；中山 = 抖动加实线山脊、山脚隐进雾里（抖动浓度往下递减）；
近景 = 黑底亮轮廓的剪影。山层都在 setup 里预先做成 Sprite，每帧只贴图。

所有 hold 都只依赖 t（没有逐帧状态），任何时刻都能直接画；小事件按 `every(t, 周期, 时长, 偏移)` 排定。
退场都用 `self.hold_t + t` 接着持续阶段最后的样子收场（不会跳回 t=0 的画面）。

## x3.cloud 坐看云起
- 依据：王维《终南别业》“行到水穷处，坐看云起时。偶然值林叟，谈笑无还期。”；陶渊明《归去来兮辞》“云无心以出岫，鸟倦飞而知还”。
- 入场（3.2s）：隐者拄杖从左边走上山石坐下，杖斜靠一旁；题诗两列逐字写出。
- 持续：远山、中山、山脚雾气；云一朵朵从中山后的山谷里冒出（出岫）、升高、长大，最后断成虚线散掉（一朵 33 秒，三朵错开）；溪水从右边流来，流到石下的小潭就没了（水穷处）。
  小事件：倦鸟一两只飞回远山（47s 一次）；林叟拄杖走来坐下，两人轮流冒“……”，不时一起“哈”大笑，然后走掉（240s 一次）；题诗每 150s 浮现一次。
- 退场（1.3s）：云海从山谷涌上来淹没整幅画，点阵自下而上熄灭。
- 点阵：小山上两团小云轮流升起。

## x3.rain 听雨
- 依据：温庭筠《更漏子》“梧桐树，三更雨……一叶叶，一声声，空阶滴到明。”；雨打芭蕉；《道德经》七十八章“天下莫柔弱于水，而攻坚强者莫之能胜”（滴水穿石）。
- 入场（2.8s）：屋檐从上方压下来，匾“听雨”晃一晃停住，各个瓦尖依次开始滴水，雨势渐密。
- 持续：一排瓦当与滴水瓦，每个瓦尖按自己的节奏（2.4–4.6s）滴水：水珠鼓起 → 落下（重力加速）→ 石阶上溅起水花、漾开一圈水纹；石阶上每个滴点下有一个小坑。一个瓦尖的水打在芭蕉叶上，叶子一颤一颤地回弹。远山在雨中若有若无，雨势缓慢起伏。
  小事件：青蛙跳上石阶、鼓腮“呱”两声再跳走（83s）；远处闷雷一闪，随后雨急一阵（151s）；蜗牛沿匾绳往上爬，十分钟一趟；“空阶滴到明”隔两分钟在石阶上浮现一次。
- 退场（1.2s）：屋檐收上去，雨停，画面淡出。
- 点阵：顶行是檐，三列雨滴落下，落地溅开。

## x3.falls 观瀑
- 依据：李白《望庐山瀑布》“日照香炉生紫烟，遥看瀑布挂前川。飞流直下三千尺，疑是银河落九天。”
- 入场（2.6s）：崖口先渗出水，水头按自由落体坠下，砸进潭里溅起一圈水花，水雾腾起；题“飞流直下 / 三千尺”。
- 持续：V 字形峡谷（崖顶受光抖动，往下转暗，斧劈皴裂线、苔点），瀑布八道水线越往下越快、越长；潭底水雾团翻涌、飞沫抛物线四溅，潭纹往两边荡开；香炉峰顶飘着烟；崖口一棵探身松；左下礁石上一人仰观。
  小事件：水雾里出一道三重的虹，从左往右画出、再从左往右淡去（130s）；落叶漂到崖口翻下去，在潭里打转漂走（53s）；燕子穿过水雾（71s）。
- 退场（1.3s）：水断，最后一截水尾落进潭里，水雾散尽，画面淡出。
- 点阵：两边崖壁，中间两列水点往下冲，底部溅花。

## x3.snow 寒江独钓
- 依据：柳宗元《江雪》“千山鸟飞绝，万径人踪灭。孤舟蓑笠翁，独钓寒江雪。”
- 入场（3.4s）：雪由疏到密，小舟从左边滑进江心，船尾拖着水纹；老翁扬竿，钓线带着浮子甩出去，落水漾开。
- 持续：三重山（最远一层只剩虚线山脊，留白即雪），江面空阔，近岸一丛寒林枝头挂雪；雪分远近三层飘落；船轻轻起伏，有倒影。
  斗笠和船舷上的积雪随时间慢慢堆白（150s 一轮），积满了老翁抖一抖，雪簌簌落下。
  小事件（47s）：浮子一点一点地动；六成会提竿——多半是空钩（钓的是雪），三成钓上一尾小鱼挂在钩上晃，然后放回、重新甩线。“千山鸟飞绝”，所以这一幕刻意没有鸟。
- 退场（1.3s）：小舟悠悠划出画外，风吹雪斜，画面淡出。
- 点阵：雪花落下，底部积雪随斗笠积雪一起变厚，抖雪时清空。

## x3.moon 望月
- 依据：苏轼《水调歌头》“明月几时有”“千里共婵娟”；张九龄《望月怀远》“海上生明月”；李白《静夜思》“举头望明月”；杜甫《月夜忆舍弟》“月是故乡明”；李清照《一剪梅》“雁字回时，月满西楼”。
- 月相：**按真实日期算**（朔望月 29.530588853 天，以 2000-01-06 18:14 UTC 的朔为起点）。盈月亮在右、亏月亮在左；带月海暗斑；暗面有极稀的“地照”和隐约轮廓。月下标月相名：朔月 / 蛾眉月 / 上弦月 / 盈凸月 / 望月 / 亏凸月 / 下弦月 / 残月。（这是本批唯一读系统时钟的地方，所以同一 seed 不同日子月相不同。）
- 入场（3.0s）：月亮从江面尽头升起，月影一道道铺开；点阵上的月亮也从下方升起。
- 持续：星空（月旁不见星）、远山、江面；月影是一条碎银，越近越宽、随波闪动，亮度随月相（满月亮、蛾眉弱）；左岸小亭（翘角攒尖、栏杆）里有人凭栏，偶尔抬头。
  小事件：一缕薄云从右往左掠过月面（97s）；一行雁排成人字从月前飞过（151s）；月影里跳起一尾鱼，落水一圈（67s）；题诗每两分钟换一句（明月几时有 / 海上生明月 / 举头望明月 / 千里共婵娟 / 月是故乡明）。
- 退场（1.3s）：云幕从右边合拢，月光收尽；点阵从右往左熄灭。
- 点阵：今晚真实的月相（朔月时只留一圈虚线），角上偶有星闪。

## x3.dawn 紫气东来
- 依据：《列仙传》“老子西游，关令尹喜望见有紫气浮关，而老子果乘青牛而过也。”（函谷关）
- 入场（3.4s）：太阳从东边云海里升起，光芒散开；三缕“紫气”从日边一路伸向西边的关楼；题“紫气东来”。
- 持续：云海三层（远小慢、近大快，云头有卷纹，形状跟着云头走不突变）；群峰露出云海，西边山坳里一座关楼（城台、门洞、垛口、两重檐）；十二道光芒长短相间、缓缓转动；紫气是三道往西流动的虚线波带，流进亮着的门洞。
  小事件：每 300s 一位老者骑青牛从东边山脊慢慢走进关门，到关前时“紫气东来”四字浮现；一行三只飞鸟掠过日前（59s）；日光一亮、光芒伸长（43s）。
- 退场（1.4s）：日光大盛，画面从西往东褪去，最后太阳收成一点。
- 点阵：底行地平线，上面一轮日，光芒旋转，日光一亮时外圈变大。

## x3.pine 松风
- 依据：《梁书·陶弘景传》（《太平御览》卷九五三引）“特爱松风，庭院皆植松，每闻其响，欣然为乐。有时独游泉石，望见者以为仙人。”陶弘景是茅山上清派宗师。
  出处：<https://ctext.org/taiping-yulan/953>
- 入场（2.6s）：一阵风从左边吹进来，老松由静到动；题“特爱松风”。
- 持续：崖上一株老松，主干扭转（粗干带暗色鳞纹），一枝长臂探向山谷，枝头十一簇平顶松盖；松下隐者坐听。离树根越远摆得越多。平时微风轻摇；每 31s 一阵大风（2s 起风、9s 落定）：风线成群掠过、松盖整排压弯回弹、松针被吹散、隐者衣袖发带飘起。远山里一线瀑布。
  小事件：松果从长臂上掉下，在石上弹两下滚到隐者脚边（73s）；题字每 140s 浮现。
- 退场（1.2s）：风止，画面淡出。
- 点阵：“松涛”波形，振幅与速度随风势，大风时加粗。

## x3.tide 观潮
- 依据：钱塘江潮。苏轼《催试官考较戏作》“八月十八潮，壮观天下无”；潘阆《酒泉子·长忆观潮》“弄潮儿向涛头立，手把红旗旗不湿”。
  出处：<https://cn-poetry.com/su-shi-poems/written-to-examiners.html>
- 视角：站在江边鱼鳞石塘上隔江远望（横向构图，前景一排看潮人，左边月轮山上一座六和塔，对岸远山一抹）。
- 入场（2.8s）：石塘从下面升上来，看潮的人一个个探出头（有人打伞、有小孩骑在大人肩上），题“八月十八潮”。
- 持续：平时江面平静，细浪由远及近（近大远小）慢慢漂。每 75 秒一潮：天边先出一道白线（一线潮），
  斜着横过江面、从右往左推过来，越近越高；潮头是一道白练，上面飞着白沫，正面一道道往下泻的水纹，近端卷下一条浪舌；
  潮头扫到石塘，浪花溅过塘顶，近处的人往后一缩，潮快到的地方大家伸长脖子、小孩招手；潮头身后江面翻涌，二三十秒才平。
  每潮大小不同；三成多的潮头上立着弄潮儿，手举旗子在风里翻，这时题句换成“弄潮儿向涛头立”，平时“八月十八潮 / 壮观天下无”轮换。
  小事件：江鸥掠过（41s）。
- 退场（1.3s）：最后一道大潮从右边漫过整幅画面，白沫退去。
- 点阵：底行江岸、细浪；潮来时一道浪墙从右往左推过点阵，高度随潮的大小。

## x3.fish 濠梁观鱼
- 依据：《庄子·秋水》濠梁之辩：“庄子与惠子游于濠梁之上。庄子曰：‘鯈鱼出游从容，是鱼之乐也。’惠子曰：‘子非鱼，安知鱼之乐？’庄子曰：‘子非我，安知我不知鱼之乐？’……庄子曰：‘请循其本……我知之濠上也。’”
  原文：<https://zh.wikisource.org/zh-hans/%E8%8E%8A%E5%AD%90/%E7%A7%8B%E6%B0%B4>
- 入场（2.6s）：从桥上俯看：石栏从下面升上来，水面的波纹渐渐平了，五尾鯈鱼从四边游进来。
- 持续：俯看一池静水：水面微光漂动，四片有缺口的荷叶、一枝荷苞；五尾细长的鯈鱼沿各自平滑的路线从容游动（尖头、前粗后细、摆尾随游速），游到荷叶下就被遮住。
  石栏上每 28s 浮出一句濠梁之辩，庄子的话靠左、惠子的话靠右，一来一回，八句循环。
  小事件：落叶飘下落水，鱼都凑过去围着啄，叶子一颤一颤，然后散开（61s）；蜻蜓飞来落在荷苞上歇一会再飞走（89s）；鱼浮上来吐个泡（19s）。
- 退场（1.2s）：鱼一摆尾往四面散开，水纹荡开，画面淡出。
- 点阵：一尾小鱼来回游，泡泡涟漪。
